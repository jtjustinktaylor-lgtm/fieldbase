# FieldBase

Business management platform for trades & service businesses.

**181 business templates** · **20 languages** · **Stripe payments** · **PDF export** · **Profit tracking**

## Quick Start

```bash
npm install
npm run dev
```

## Features

- 📋 Quotes & Estimates — professional PDF quotes with line items, tax, notes
- 📅 Job Management — schedule, track, convert quotes to jobs to invoices  
- 💰 Invoices & Payments — Stripe Checkout integration, payment links, PDF export
- 📊 Profit Tracker — revenue, costs, margins, expense breakdown per job
- 👥 Customer CRM — history, notes, contact info, job timeline
- 📦 Inventory — parts tracking, low-stock alerts, cost management
- 📱 PWA — works offline, installable on any device
- 🌍 20 Languages — English, Spanish, French, German, Chinese, Japanese, and more
- 🏢 181 Business Templates — plumbing, HVAC, electrical, landscaping, cleaning, consulting, and 175+ more

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- jsPDF (PDF generation)
- Recharts (charts)
- PWA (service worker, offline support)

## Stripe Integration

Set your Stripe keys in Settings → Integrations:
- **Test mode**: Use `pk_test_` keys for development
- **Live mode**: Switch to `pk_live_` keys for production
- **Demo mode**: Works without keys for testing the flow
